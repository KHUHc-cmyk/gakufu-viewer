# 楽譜ビューア

iPad の Safari で楽譜を見るための静的な Web アプリです。ページは2つあります。

- **楽譜ビューア(MXML)**（`index.html`）：ソロギターアレンジの出力（MusicXML。ギターの TAB つき・music21 が出力）を、見て聴く
- **楽譜ビューア(PDF)**（`pdf.html`）：PDF の楽譜を、めくって見る（下の「PDF の楽譜のページ」）

楽譜はブラウザの中で読むだけで、外へは送りません。部品（alphaTab 1.8.4・pdf.js 6.3.289）・フォント・音源・ワーカーはリポジトリに同梱していて、外の配信元は使いません。

公開先：https://khuhc-cmyk.github.io/gakufu-viewer/ （PDF のページは https://khuhc-cmyk.github.io/gakufu-viewer/pdf.html 。main に push するたびに、テストが通れば出し直します）

## 使い方（楽譜ビューア(MXML)）

1. 上の URL を iPad の Safari で開く。最初は楽譜が開かず、「「ファイルを選ぶ」で、楽譜を開いてください」と出る
2. 楽譜を開く
   - 「ファイルを選ぶ」から（いくつでも一度に選べる。種類は絞っていない）。開いたファイルは選び欄の「開いたファイル」に並び、切り替えられる（選び欄は、楽譜を開くと出る）
   - 開けるもの：`.musicxml`・`.xml`・圧縮された `.mxl`。alphaTab が読めるほかの形式（Guitar Pro の `.gp3`・`.gp4`・`.gp5`・`.gpx`・`.gp` など）は、整えずにそのまま開く（`.gp` はテストで確かめた。ほかはテスト用のファイルが無く、未確認）
3. 「再生」で鳴らす。もう一度押すと一時停止。「停止」で頭へ戻る
4. 小節をタップすると、その小節の頭へ移る（再生中はそこから続ける）
5. テンポ：50〜200%（5% きざみ）。右の数字を押すと 100% に戻る
6. くり返し：「くり返し」に印を付けると、何度も鳴らす。はじめの範囲は曲の全部（印を付けるだけで、通してくり返す）。「小節 □ 〜 □」に番号を入れると、その範囲だけになる（範囲は色が付く。全部のときは付かない）。印は端末に覚える（範囲は覚えない）。「ここから」「ここまで」を押すと、いまいる小節（タップした小節・鳴っている小節）が入る
7. メトロノーム・カウントイン：印を付けると鳴る
8. 再生中は画面が暗くならない（iPadOS 16.4 以降）
9. 明るい／暗いは、iPad の設定に合わせて変わる
10. 聴き比べ：「聴き比べ」の行の A／B／C に楽譜を割り当て、ボタンを押して切り替える。同じ小節の位置のまま切り替わり、再生中なら続けて鳴る。くり返しの範囲・テンポもそのまま
    - はじめは A・B・C とも「（なし）」。「ファイルを選ぶ」で開いたファイルは、空いている所へ A→B→C の順に入る
    - 小節の数が違う楽譜へ切り替えて、その小節が無いときは最後の小節へ移る
11. 大きさ：楽譜を 小・中・大 から選ぶ
12. たたむ：操作の欄をたたんで、楽譜を広く見せる（再生・停止・テンポの行だけ残る）。「ひらく」で戻る
13. テンポ・メトロノーム・カウントイン・大きさは、この端末の中に覚えて、次に開いたときも同じになる（外へは送らない）
14. ほかのツールから受け取る：「コード進行練習補助」などが作った楽譜を、ファイルに保存せずに URL で受け取って開ける（URL の `#` より後ろに入れるので、外へは送られない）。受け取ると「コード進行へ」のボタンが出て、元のツールへ戻れる。決まりは `docs/受け渡しの決まり.md`
15. 鳴らすパート：パートが2つ以上ある楽譜（コード・ベース・ドラムの伴奏など）では、「鳴らすパート」の行にパートごとのボタンが出る。押すと、そのパートの音だけ消える（もう一度押すと戻る。「全部鳴らす」で全部戻る）。楽譜の表示は変わらない
    - 再生中に押すと、約0.5秒おくれて効く（先に作ってある音が鳴り終わってから）
    - 消したパートは、同じ名前のパートがある別の楽譜に替えても消えたまま（聴き比べで、ベースだけを比べられる）。ページを開き直すと、全部鳴る状態に戻る
16. オフライン：一度開くと、アプリ・音源が端末に保存される（「この端末に保存済み」と出る）。その後は電波が無くても開けて再生できる。新しい版を出したときは、電波のある所で開けば、その場で新しいページになる（ページと `src/` は、電波があれば新しいものを先に取りに行く。取れないとき・3秒たっても返らないときは、保存してあるものを出す）

音が出ないとき：消音（コントロールセンターのベル）と音量を確かめる。それでも出ないときは、URL の末尾に `?out=sp` を付けて開く（別の鳴らし方）。

## PDF の楽譜のページ（楽譜ビューア(PDF)）

世間の PDF 楽譜ビューア（forScore・Piascore・MobileSheets など）にある機能のうち、めくって弾くのに要るものを入れています。

1. 開く：「ファイルを選ぶ」で PDF を選ぶ（いくつでも）。開いた PDF は「本棚」に残り、次にページを開くと、最後に開いた PDF が前回のページから出る
   - 本棚は、この端末のブラウザの中（IndexedDB）だけに保存する。外へは送らない。「消す」で消えるのは、本棚の写しだけ（もとのファイルは消えない）
   - ブラウザのデータを消すと、本棚も空になる。パスワードつきの PDF は開けない
2. めくる：画面の右をタップ＝次・左をタップ＝前・左右にはらう・「前へ」「次へ」・ページのスライダー
   - キーボードと、キーボードとしてつながる譜めくりペダル：← →・↑ ↓・PageUp／PageDown・スペース・Enter（Home／End で最初・最後のページ）
3. 真ん中をタップ：操作の欄を出す／かくす（かくすと、楽譜が画面いっぱいになり、下にページの数字だけ出る）。「たたむ」は、めくる行だけを残す（せまい画面では、はじめから たたんである）
4. 表示：自動（縦長の画面＝1ページ・横長の画面＝見開き。画面の向きで決まる）／1ページ／見開き／縦スクロール
5. 半ページめくり：1ページ表示で、めくると、まず上半分に次のページが出る（下半分は今のページのまま）。もう1回で次のページになる
6. 余白カット：ページごとに、中身のある所だけを大きく出す
7. 色：ふつう／セピア／夜（白黒を逆に）
8. 縦スクロール：ページが縦につながる（幅に合わせる）。自動スクロールは速さ 1〜20。動いている間に真ん中をタップすると止まる
9. 楽譜を開いている間は、画面が消えない。設定（表示・半ページめくり・余白カット・色・速さ）は端末に覚える
10. オフライン：一度開くと、pdf.js の部品も端末に保存され、電波が無くても PDF を開ける
11. しおり：いまのページに名前を付けておき、押すとそのページへ飛ぶ（1ページに1つ）。PDF に目次が入っていれば、それも並ぶ
12. 書き込み：黒・赤・青のペン、蛍光ペン、消しゴム（触れた線を1本ずつ消す）、「元に戻す」「このページを消す」
    - 書き込み中は、タップやはらう動きではめくらない（「前へ」「次へ」かキーでめくる）
    - 線は、紙の上の位置で覚える。余白カットや表示を変えても、同じ所に出る。PDF のファイルそのものは変えない
13. メトロノーム：速さ 40〜240・拍子 2／3／4／6（小節の頭は高い音）
14. しおりと書き込みも、本棚と同じく、この端末のブラウザの中だけに保存する。本棚から消すと、いっしょに消える
15. セットリスト：本番の曲順に、本棚の PDF を並べておく（「↑」「↓」で並べ替え・「外す」。同じ曲を2回入れてもよい。いくつでも作れる）
    - 曲を押すと、その曲の頭から開く。最後のページで「次へ」を押すと次の曲の頭へ、最初のページで「前へ」を押すと前の曲の最後のページへ移る（タップ・はらう・ペダルも同じ）
    - 題名の頭に「2/5」（何曲目/曲数）が出る。開き直しても、セットリストの続きから開く。本棚や「ファイルを選ぶ」から開くと、セットリストから抜ける
    - セットリストも、この端末のブラウザの中だけに保存する。本棚から消した曲は、セットリストからも外れる
16. 本棚を名前で探す：打つたびに絞り込む（全角と半角・大文字と小文字・ひらがなとカタカナ を区別しない。空白で区切ると、全部の言葉が入っているものだけ）。「並び」で、最近開いた順／名前の順 を選べる（端末に覚える）
17. 右に回す：横倒しの PDF を直す。押すたびに、その PDF の全部のページが右へ 90 度回る（4回で元に戻る）。向きは、PDF ごとに本棚に覚える。書き込みも、紙といっしょに回る。PDF のファイルそのものは変えない。「このページだけ回す」（書き込み・メトロノームの行の右端）は、いまのページだけを回す（見開きでは左のページ。曲集の中の横向きのページなど）。「右に回す」の向きに足す分として、ページごとに覚える

## 整える層（`src/prepare.js`）

alphaTab に渡す前に MusicXML を整え、読み込んだ後のモデルにも手を入れます。

1. **2段目が TAB の段（clef の sign が TAB）のときだけ**、TAB の段に重ねて書かれた音を外し、残った1段を「五線＋TAB」で描く。外した音の長さは `<forward>` に置き換えるので、位置はずれない。それ以外（ピアノ譜・複数パート・TAB だけの1段など）は音を外さない
2. hammer-on / pull-off を読み取り、モデルに付け直す（alphaTab 1.8.4 は、音を拍に入れた後で弦の番号を読むため、弦ごとの引き当てが空になって全部落ちる。引き当てを作り直してから付ける）
3. コード名を自前で組み立てる：分数コードのベース音（`C/E`）・degree（`Fadd9`）を入れる。kind の `text` 属性があればそれを使う（music21 の書き方）。小節の途中の `<offset>` つきのコードは alphaTab が落とすので、その位置の音の前へ動かす
4. ハーモニクス（`<harmonic>`）を付け直す（alphaTab 1.8.4 は読まない）。ナチュラルは触れるフレット、人工ハーモニクスは1オクターブ上として鳴らす
5. 練習番号を、小節の最初の拍の文字に移す（alphaTab 1.8.4 は練習番号とコード名を同じ行に置き、文字が重なるため）
6. 2つ目の声部の休符のうち、コード名・文字と同じ拍にあって重なるものを見えなくする（長さと音は変わらない。alphaTab 1.8.4 は、この休符を譜表の上へ押し上げるが、コード名の行の高さを決めた後なので重なる）

## 手元で動かす

```sh
npm install
npm test            # Node のテスト（整える層＋読み込み）
npm run test:ui     # 画面のテスト（Playwright の Chromium）
npm run serve       # http://127.0.0.1:8080/ で開く
```

## 中身

- `index.html`・`src/app.js`・`src/style.css` … 楽譜ビューア(MXML) の画面
- `pdf.html`・`src/pdf-app.js`・`src/pdf.css` … 楽譜ビューア(PDF) の画面。`src/pdf-layout.js` … めくり・収め方・余白カットの計算（画面と Node のテストで同じものを使う）。`src/pdf-store.js` … 本棚と、しおり・書き込みの保存（IndexedDB）。`src/pdf-ink.js` … 書き込み・しおりの計算。`src/pdf-metronome.js` … メトロノーム。`src/pdf-setlist.js` … セットリストの計算。`src/pdf-shelf.js` … 本棚を探す・並べる計算
- `sw.js` … オフライン用の保存（Service Worker）。保存の版は、Pages に出すときにコミットの番号へ置き換わる
- `src/load.js` … ファイルのバイト列 → alphaTab のモデル（画面と Node のテストで同じものを使う）
- `src/prepare.js` … 整える層
- `src/mxl.js` … `.mxl`（zip）から楽譜の XML を取り出す
- `vendor/alphatab/` … alphaTab 1.8.4（MPL-2.0）。フォント Bravura（SIL OFL）・音源 sonivox（Apache-2.0）も同梱。入れ直すときは `scripts/vendor-alphatab.sh`
- `vendor/pdfjs/` … pdf.js 6.3.289（Apache-2.0。古めの Safari でも動く legacy 版）。文字の対応表（cmaps）・基本のフォント・画像の読み手（wasm）も同梱。`files.json` は、オフライン用に保存する一覧。入れ直すときは `scripts/vendor-pdfjs.sh`
- `samples/` … テストの材料の楽譜（著作権の切れた曲）。画面には出さず、公開するページにも入れない（2026-10-11 に見本をやめた）
- `test/` … Node のテスト。`test/fixtures/` は自作の音階だけの試験用（作り直しは `node test/fixtures/make-fixtures.js`）。PDF の試験用は、テストがその場で作る（`test/fixtures/make-pdf.js`。枠の線とページ番号だけ）
- `test-ui/` … 画面のテスト
- `.github/workflows/pages.yml` … main に push するたびに、両方のテストを通してから Pages に出す

## 分かっている不具合・まだ確かめていないこと

- 第1版・第2版（聴き比べ・オフライン）は iPad の実物で確かめた。131小節の曲の速さは未確認
- ハーモニクスは、自作の試験用でしか確かめていない。実物の出力（約90個）の書き方が違えば、付け直せないことがある。そのときは読み込み後の知らせ欄に「付け直せなかった奏法 N個」と出る
- 人工ハーモニクスは、楽譜に書いてある触れる位置にかかわらず「1オクターブ上」として鳴らす
- 練習番号は、四角い枠のない斜めの文字で出る（重なりを避けるため）
- コード名と重なる2つ目の声部の休符は、見えなくしている（上の 6）。コード名の無い拍では、休符が譜表の上に出ることがある
- `.mxl` は、Safari 16.4 より前（`DecompressionStream` が無い）だと中身を取り出せない。そのときは alphaTab にそのまま読ませるので開けるが、整える層を通らない（TAB の段の音が2重に鳴る）
- 開いたファイルは、ページを閉じる・読み込み直すと消える（端末にも外にも残さない）。オフラインで保存されるのはアプリだけ。Google ドライブの楽譜を電波の無い所で開くには、iPad の「ファイル」で、その楽譜を端末にダウンロードしておく
- 聴き比べで切り替えると、新しい楽譜を描き直すため、音が一瞬（1秒ほど）止まる
- くり返しの範囲は、反復記号がある曲では、その小節が最初に出てくる所を使う
- PDF のページの第1版（開く・めくる・見開き・半ページめくり・余白カット）と第2版（書き込み・しおり・メトロノーム・たたむ）・第3版（セットリスト）・本棚を名前で探す・並べる・「右に回す」は iPad の実物で確かめた。スキャンした重い PDF の速さも未確認
- PDF のページを、ほかのサイトの枠（iframe）の中で開くと、Safari が本棚を別に保存し、Safari を閉じた後に消すことがある。残したいときは、「別のタブで大きく開く」で単体のページを使う
- PDF の余白カットは、スキャンの黒いふちや小さなごみがあると、切れる量が少なくなる。Apple Pencil だけで書く切り替え・書き込みつきの PDF の書き出し・ページごとに別の向きに回すことは、まだ無い
- alphaTab 1.8.4 で、`api.midiLoaded` に登録するとページが止まる不具合がある（ワーカーを使うとき）。このアプリでは使わず、`playerReady` で代わりにしている
