# 楽譜ビューア

ソロギターアレンジの出力（MusicXML。ギターの TAB つき・music21 が出力）を、iPad の Safari で見て聴くための静的な Web アプリです。
楽譜はブラウザの中で読むだけで、外へは送りません。部品（alphaTab 1.8.4）・フォント・音源・ワーカーはリポジトリに同梱していて、外の配信元は使いません。

公開先：https://khuhc-cmyk.github.io/gakufu-viewer/ （main に push するたびに、テストが通れば出し直します）

## 使い方

1. 上の URL を iPad の Safari で開く。最初は見本（Aura Lea）が開く
2. 楽譜を開く
   - 見本は、上の選び欄から選ぶ
   - 自分の楽譜は「ファイルを選ぶ」から（いくつでも一度に選べる。種類は絞っていない）。開いたファイルは選び欄の「開いたファイル」に並び、切り替えられる
   - 開けるもの：`.musicxml`・`.xml`・圧縮された `.mxl`。alphaTab が読めるほかの形式（Guitar Pro など）は、整えずにそのまま開く
3. 「再生」で鳴らす。もう一度押すと一時停止。「停止」で頭へ戻る
4. 小節をタップすると、その小節の頭へ移る（再生中はそこから続ける）
5. テンポ：50〜120%（5% きざみ）
6. くり返し：「小節 □ 〜 □」に番号を入れて「くり返し」に印を付ける。その範囲だけを何度も鳴らす（範囲は色が付く）
7. メトロノーム・カウントイン：印を付けると鳴る
8. 再生中は画面が暗くならない（iPadOS 16.4 以降）
9. 明るい／暗いは、iPad の設定に合わせて変わる

音が出ないとき：消音（コントロールセンターのベル）と音量を確かめる。それでも出ないときは、URL の末尾に `?out=sp` を付けて開く（別の鳴らし方）。

## 整える層（`src/prepare.js`）

alphaTab に渡す前に MusicXML を整え、読み込んだ後のモデルにも手を入れます。

1. **2段目が TAB の段（clef の sign が TAB）のときだけ**、TAB の段に重ねて書かれた音を外し、残った1段を「五線＋TAB」で描く。外した音の長さは `<forward>` に置き換えるので、位置はずれない。それ以外（ピアノ譜・複数パート・TAB だけの1段など）は音を外さない
2. hammer-on / pull-off を読み取り、モデルに付け直す（alphaTab 1.8.4 は、音を拍に入れた後で弦の番号を読むため、弦ごとの引き当てが空になって全部落ちる。引き当てを作り直してから付ける）
3. コード名を自前で組み立てる：分数コードのベース音（`C/E`）・degree（`Fadd9`）を入れる。kind の `text` 属性があればそれを使う（music21 の書き方）。小節の途中の `<offset>` つきのコードは alphaTab が落とすので、その位置の音の前へ動かす
4. 練習番号を、小節の最初の拍の文字に移す（alphaTab 1.8.4 は練習番号とコード名を同じ行に置き、文字が重なるため）

## 手元で動かす

```sh
npm install
npm test            # Node のテスト（整える層＋読み込み）
npm run test:ui     # 画面のテスト（Playwright の Chromium）
npm run serve       # http://127.0.0.1:8080/ で開く
```

## 中身

- `index.html`・`src/app.js`・`src/style.css` … 画面
- `src/load.js` … ファイルのバイト列 → alphaTab のモデル（画面と Node のテストで同じものを使う）
- `src/prepare.js` … 整える層
- `src/mxl.js` … `.mxl`（zip）から楽譜の XML を取り出す
- `vendor/alphatab/` … alphaTab 1.8.4（MPL-2.0）。フォント Bravura（SIL OFL）・音源 sonivox（Apache-2.0）も同梱。入れ直すときは `scripts/vendor-alphatab.sh`
- `samples/` … 動作テスト用の楽譜（著作権の切れた曲）
- `test/` … Node のテスト。`test/fixtures/` は自作の音階だけの試験用（作り直しは `node test/fixtures/make-fixtures.js`）
- `test-ui/` … 画面のテスト
- `.github/workflows/pages.yml` … main に push するたびに、両方のテストを通してから Pages に出す

## 分かっている不具合・まだ確かめていないこと

- **iPad の実物ではまだ確かめていない**（音が出ることだけ確認済み）。131小節の曲の速さも未確認
- ハーモニクスは、ふつうの音（フレットどおりの高さ）として鳴らし、TAB にもふつうのフレットの数字で出る（alphaTab 1.8.4 は `<harmonic>` を読まない。付け直さないと決めた）
- 練習番号は、四角い枠のない斜めの文字で出る（重なりを避けるため）
- 上の声部の休符が、コード名と重なることがある（例：見本の Jingle Bells の2・7小節。alphaTab の配置による）
- `.mxl` は、Safari 16.4 より前（`DecompressionStream` が無い）だと中身を取り出せない。そのときは alphaTab にそのまま読ませるので開けるが、整える層を通らない（TAB の段の音が2重に鳴る）
- 開いたファイルは、ページを閉じる・読み込み直すと消える（端末にも外にも残さない）
- くり返しの範囲は、反復記号がある曲では、その小節が最初に出てくる所を使う
- alphaTab 1.8.4 で、`api.midiLoaded` に登録するとページが止まる不具合がある（ワーカーを使うとき）。このアプリでは使わず、`playerReady` で代わりにしている
