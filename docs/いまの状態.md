## alphaTab 1.8.4 の不具合と、その避け方

- hammer-on / pull-off が全部落ちる → 弦ごとの引き当てを作り直して付け直し、`score.finish` をもう一度走らせる
- `<harmonic>` は読み飛ばされる → 自前で付ける（表示も音もハーモニクス）
- 小節の途中のコード（`<offset>`）は2つ目以降が落ちる → その位置の音の前へ動かす
- 練習番号とコード名が重なる → 練習番号を拍の文字にする
- 上の声部の休符がコード名と重なる → 重なる休符を見えなくする
- `api.midiLoaded` に登録するとページが止まる → 使わない（`playerReady` を使う）
- 中に別の .xml がある `.gp` を楽譜と取り違える → 直した
- 再生の直後に止めると、無音の出口が残る → 出口が動き出すまで、止める操作を待つ
