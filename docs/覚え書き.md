# 覚え書き（楽譜ビューア）

2026-10-14 に `docs/いまの状態.md` から移した。alphaTab の不具合と避け方・決まっていること・まだ分からないこと。

## alphaTab 1.8.4 の不具合と、その避け方

- hammer-on / pull-off が全部落ちる → 弦ごとの引き当てを作り直して付け直し、`score.finish` をもう一度走らせる
- `<harmonic>` は読み飛ばされる → 自前で付ける（表示も音もハーモニクス）
- 小節の途中のコード（`<offset>`）は2つ目以降が落ちる → その位置の音の前へ動かす
- 練習番号とコード名が重なる → 練習番号を拍の文字にする
- 上の声部の休符がコード名と重なる → 重なる休符を見えなくする
- `api.midiLoaded` に登録するとページが止まる → 使わない（`playerReady` を使う）
- 中に別の .xml がある `.gp` を楽譜と取り違える → 直した
- 再生の直後に止めると、無音の出口が残る → 出口が動き出すまで、止める操作を待つ
- 描画が終わる前（並びの情報が前の楽譜のまま）に `highlightPlaybackRange` を呼ぶと例外になる → 新しい楽譜の拍が並びの情報に入るまで待ち、`postRenderFinished` でもう一度付ける
- 描画が終わる前に小節の少ない楽譜へ替えると、前の楽譜の描画の結果が遅れて届き、中で例外が1回出る（画面は次の描画で直る。直していない。画面のテストは、並び終わるのを待ってから替える）

## 決まっていること

- アプリだけ公開。楽譜は Google ドライブで iPad へ渡し、ブラウザの中で読むだけ
- `samples/` は著作権の切れた2本（`aura_lea_jazz`・`jingle_bells_pop`）。テストの材料で、画面と公開ページには出さない。著作権のある曲はリポジトリに入れない（本人が iPad で開いて再生するのは、対象のうち）
- 自作の試験用は `test/fixtures/`（音階だけ。`make-fixtures.js` で作り直せる）
- ほかの MusicXML（将来、購入した楽譜など）も開けるようにする
- 画面のテストをこの PC で走らせる準備（`npm install`・`npx playwright install chromium`）は済み
- クレジットの記録は PC の `local/クレジットの記録.md`（公開しない）
- iCloud に残る古い楽譜の片付けは、このアプリでは作らない（2026-10-06。iPad の Safari はページからファイルを消せない。本人が別のツールで対応する）

## まだ分からないこと

- 実物の出力のハーモニクス（約90個）が付け直せるか（自作の試験用では付く）／`.gp3`〜`.gp5`・`.gpx` が開けるか
- 実物の 131小節の曲の、iPad での速さ（PC では速い）
- PDF：スキャンした重い PDF の速さ／枠の中（コード進行練習補助のタブ）で、本棚・しおり・書き込みが Safari を閉じた後も残るか（残らなければ「別のタブで大きく開く」を使う）
