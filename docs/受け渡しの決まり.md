# 受け渡しの決まり（ほかのツール → 楽譜ビューア）

2026-10-10 に決めた。ほかのツール（いまは「コード進行練習補助」）が作った MusicXML を、**ファイルに保存せずに**楽譜ビューアへ渡すための決まり。受け取る側のコードは `src/incoming.js`、テストは `test/incoming.test.js` と `test-ui/ui.test.js` の「受け取り：…」。

## 形

楽譜ビューアの URL の **`#` より後ろ**に入れる。`#` より後ろはサーバーへ送られないので、楽譜はブラウザの外へ出ない。

```
https://khuhc-cmyk.github.io/gakufu-viewer/#name=<名前>&z=<楽譜>&back=<戻り先>
```

| 名前 | 中身 |
|---|---|
| `z` | MusicXML（UTF-8）を **deflate-raw** で縮めて **base64url** にしたもの（`+`→`-`、`/`→`_`、末尾の `=` は取る） |
| `name` | 楽譜の名前（`encodeURIComponent` する）。選び欄と聴き比べに出る。無ければ「受け取った楽譜 1」 |
| `back` | 戻り先の URL（`encodeURIComponent` する）。**`https://script.google.com/` のものだけ**受け取る。省いてよい |

- `name` と `z` の組は **3つまで**並べられる（`name=…&z=…&name=…&z=…`）。順に、聴き比べの A・B・C の空いている所（または見本の入っている所）に入り、1本目が開く
- 1本あたり、戻した後の大きさは 5MB まで
- 長さの目安：コード進行練習補助の伴奏つき（35〜60KB）は、縮めると 約2,000〜2,500字。3本で 約6,600字

## 受け取った後の動き

- 楽譜は「開いたファイル」に足される（「ファイルを選ぶ」で開いたのと同じ扱い）
- 楽譜ビューアを開いたまま、同じタブに次の URL が来たとき（`#` より後ろだけが変わったとき）も、足して開く
- `back` は端末の中（localStorage）に覚え、「コード進行へ」のボタンを出す。次に `#` なしで開いても出る。**戻り先の URL は、リポジトリには書かない**（本人だけの URL のため）
- 中身が壊れているときは、「受け取った楽譜を読めませんでした」と出して、見本（または、いまの楽譜）のままにする
- `z` を付けず `back` だけを渡すと、戻り先を覚えるだけ（ただのリンクとして使える）

## 枠（iframe）で使うとき（2026-10-10。コード進行練習補助のタブ「楽譜ビューア」）

- 渡す側のページに `<iframe>` を置き、`src` に上の形の URL を入れる。楽譜ビューアを読み込んだ後は、`#` より後ろだけを変えた URL を `src` に入れ直すと、読み直さずに次の楽譜が開く
- 同じ楽譜をもう一度渡すときのために、`&t=<時刻>` などを足して URL を毎回変える（楽譜ビューアは、知らない名前を読み飛ばす）
- 枠は、渡す側の画面を描き直しても消えない所に置く（消すと、楽譜ビューアを読み直すことになる）。見せないときは `hidden` にする（鳴っている音は続く）
- `allow="autoplay; screen-wake-lock"` を付ける
- 枠の中では `back` を渡さない（戻るボタンは要らない）。新しいタブを開かないので、「押してから縮めない」の注意も当てはまらない
- 本人が iPad の Safari で確かめた：楽譜が出る・音が出る・スクロールと小節のタップ・ファイル選び（Apps Script のテスト用 URL で）

## 渡す側の書き方（見本）

```js
// xmlText：MusicXML の文。返り値：z に入れる文
async function packForViewer(xmlText) {
  var stream = new Blob([xmlText]).stream().pipeThrough(new CompressionStream('deflate-raw'));
  var bytes = new Uint8Array(await new Response(stream).arrayBuffer());
  var bin = '';
  for (var i = 0; i < bytes.length; i++) bin += String.fromCharCode(bytes[i]);
  return btoa(bin).split('+').join('-').split('/').join('_').split('=').join('');
}

function viewerUrl(fileName, z, backUrl) {
  return 'https://khuhc-cmyk.github.io/gakufu-viewer/#name=' + encodeURIComponent(fileName)
    + '&z=' + z + (backUrl ? '&back=' + encodeURIComponent(backUrl) : '');
}
```

## 渡す側の注意

- **押してから縮めない。** Safari は、ボタンを押した後に待ち（`await`）が入ると、新しいタブを開かせない。楽譜を作った時点で `z` を作っておき、`<a href="…" target="_blank">` の `href` に入れておく（押すだけで開く形にする）
- Apps Script の画面は枠（iframe）の中で動く。リンクには `target="_blank"`（別のタブ）か `target="_top"`（同じタブ）が要る
- 戻り先（ウェブアプリの URL）は、サーバー側の `ScriptApp.getService().getUrl()` で取れる
- `CompressionStream` は Safari 16.4 以降
- 確かめ方：作った URL を楽譜ビューアで開き、名前・小節の数・音が合うかを見る。受け取る側のテストは、見本を縮めて戻すと1バイトも変わらないことを見ている
