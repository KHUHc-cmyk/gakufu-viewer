# クラウドに渡す文

> **もう使わない（2026-10-05）。** 作る場所をクラウドセッションからローカル（PC）へ移した。下の文は、経緯の記録として残してある。いまの状態は `docs/いまの状態.md`。

クラウドセッションを始めるとき、リポジトリ `gakufu-viewer` を選んで、下のコードブロックの中身を貼る。

## セッション①（音の確認 → 第1版）

```
このリポジトリに、MusicXML（ギターの TAB つき・music21 が出力）を iPad の Safari で表示・再生する静的な Web アプリを作ってください。最初に CLAUDE.md と docs/いまの状態.md を読んでください。
- alphaTab 1.8.4 を使い、フォント・サウンドフォント・ワーカーはリポジトリに同梱する（外の CDN に頼らない）
- 最初に「音が出るだけの1ページ」（samples/ の1本＋再生ボタン1つ）を作り、GitHub Actions で Pages に出して、そこで止まって報告する。iPad で音が出たと言われてから先へ進む
- alphaTab に渡す前に MusicXML を整える層を作る：(1) 2段目（TAB の段）に重ねて書かれた音を外し、1段を「五線＋TAB」で表示する (2) hammer-on / pull-off を読み取り、読み込み後のモデルに付け直す (3) 分数コードのベース音を含めたコード名を組み立てる (4) ハーモニクスが拾われるか確かめ、だめなら付け直す
- 整える層の (1) は、2段目が TAB の段（clef の sign が TAB）のときだけ働かせる。それ以外の MusicXML（ほかのソフトの出力・ピアノ譜・複数パートなど）は、音を外さずにそのまま表示・再生する。テストに「2段のピアノ譜の小さな試験用を読ませて、音の数が減らない」を入れる。圧縮された形式（.mxl）を選んだときに読めるかも確かめ、読めなければ README の分かっている不具合に書く
- samples/ の2本（aura_lea_jazz・jingle_bells_pop）には、分数コード・ハーモニクス・3連符が無い。これらは、音階だけの小さな試験用 MusicXML をテストのフォルダに自作して試す（既存の曲を写さない）
- 機能：ファイルを選ぶ（複数。選べる種類を絞らない）／五線＋TAB とコード名の表示／再生・停止・カーソル／小節タップで頭出し／テンポ 50〜120%／小節範囲のくり返し／メトロノーム・カウントイン／再生中の画面スリープ防止／明暗は端末の設定に合わせる
- 楽譜はブラウザの中で読むだけにし、外へ送る通信を書かない。画面の文はすべて日本語
- テストの中心は Node で動かす（整える層＋読み込み。整えた後の音の数が、1段目の音の数と一致すること）。Playwright が入るなら画面のテストも足す（小節の数・再生ボタンの状態・幅 820px と 1180px で横にはみ出さない）
- main への push ごとに Pages へ出す
- 曲のデータを足さない（samples/ にあるものと、自作した音階だけの試験用だけを使う）。本人の名前やメールをコードと履歴に書かない
終わりの条件：テストが全部通る／Pages の URL で samples を開いて再生できる／README に使い方と分かっている不具合がある／docs/いまの状態.md を直してある
```

## セッション②（直し＋第2版）

第1版を本人が iPad で見た後に、見つかった直しを足して書く。骨組みは次のとおり。

```
docs/いまの状態.md を読み、「第1版で見つかった直し」を全部直してください。その後、第2版を作ってください。
- 聴き比べ：2〜3本を並べ、同じ小節の位置のまま A／B／C を切り替えて再生する
- オフライン：一度開けば、電波が無くても開けて再生できる
終わりの条件：テストが全部通る／Pages に出ている／docs/いまの状態.md を直してある
```
